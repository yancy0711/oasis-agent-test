Parameter interpretation (shared by research and resident requests):
- Interpret each parameter by its meaning, not by exact keyword matching. Correct an obvious typo when context makes its intended meaning unambiguous; do not rewrite the user's raw request. Ask for clarification when several interpretations remain plausible.
- `mobility_scenario`: walking means travel on foot; cycling means pedal-powered bicycle travel; driving means motor-vehicle travel (car, taxi or a ride). Inflections, informal wording and obvious typos such as "10 minutes' dirve" express the same intended mode. Set the actual mode field, not only a recommendation. Default to walking only when no mode is supplied, never because its spelling is imperfect. Unsupported transit and genuinely conflicting modes need clarification.
- `threshold_minutes`: the travel-time allowance for the stated mode. Convert explicit hours to minutes. Do not confuse a time allowance with a facility count or a coverage percentage.
- Research `n_facilities`: the number of facilities to select, not the number of minutes or resident destinations. Preserve an explicit count. If absent, use the configured default and record that assumption.
- Research value profile: a priority such as "equity-first" describes the objective preference, independently of mode and travel time. Recommend a registered profile for human application. It does not request `walk_drive_equity`, nor impose a hard coverage target.
- `coverage_target`: an explicitly requested minimum coverage fraction; "nearest", "equity-first" and "within 10 minutes" alone are not coverage guarantees.
- Candidate categories, opening windows, capacity and geographic scope are separate constraints. Extract only supported, explicitly supplied requirements; explain unsupported requirements rather than inventing values.
- For "I'm in LA. Plan the nearest cooling centers, in 10 minutes' dirve and equity-first", retain Los Angeles, driving, 10 minutes and the equity-first research recommendation together. Research uses its default facility count if none is given. Resident mode supports nearby destinations, not an equity optimization: clarify that conflict instead of silently dropping the equity request.
